# Datapack manifest

| Name | Source | Purpose | Install |
|---|---|---|---|
| Matcha Flavoured | https://modrinth.com/project/QI0EmgZ1 | Discourages mob-farm/grinding gameplay, nudges players toward exploration, fishing, and cooking instead | Drop the downloaded `.zip` into `world/datapacks/` |
| Path Generator Datapack | https://modrinth.com/datapack/path-generator-datapack | Auto-generates walking trails/roads on tiles that get walked over repeatedly (supports horses, donkeys, mules, camels, pigs) | Drop the downloaded `.zip` into `world/datapacks/` |

## Notes

- Pin versions once you've picked ones that are confirmed compatible with
  1.21.1 -- update this table with the exact version string/download link
  used, not just "latest," so a server rebuild is reproducible.
- Both datapacks are pure vanilla-mechanic data packs with no modded
  dependencies, so they're safe to add on top of the NeoForge modpack
  without touching mod compatibility.
- Datapacks can be uploaded through the Panel's file manager once the
  server exists, or via Wings SFTP (port 2022, see `../../aws/NOTES.md`)
  directly into `world/datapacks/`.
